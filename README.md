# Team 3nity - Login & Team Page

A simple web application featuring a login page and an interactive team overview page.

## Features

### Login Page
- Clean and modern login interface
- Username and password authentication
- Error message display for invalid credentials
- Redirects to team page upon successful login

### Team Page
- Interactive table displaying team member names as clickable links
- Modal popup system to view member details
- Background image with team.jpg
- Displays member information including:
  - Profile photo (where available)
  - Role/Position
  - Description

## How to Use

1. Open `index.html` in a web browser
2. Enter your credentials to log in
3. Upon successful login, you'll be redirected to the team page
4. Click on any team member's name to view their details in a popup modal
5. Close the modal by clicking the X button or clicking outside the modal
